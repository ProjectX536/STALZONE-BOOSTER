## Этап 2 — Безопасный игровой профиль

- [x] `GamingProfileManager` (автомат состояний), `GameSessionCoordinator` (подготовка сессии, автозапуск, обнаружение игры опросом)
- [x] `ChangeJournal`, `SnapshotStore`, атомарная запись журнала
- [x] `RollbackManager`, `StartupRecovery`, `RecoveryValidator`
- [x] `ProfileMatcher`, `ProfileRepository`, `ProfileNormalizer`
- [x] Действие: временная схема питания (`ask-first`)
- [x] Действие: приоритет игры (`optional`)
- [x] Действие: обнаружение фона и закрытие только выбранных пользователем приложений (`ask-first`)
- [x] `Competitive.json`
- [x] Скрипт `06-Verify-Restore.ps1`
- [x] Экран журнала и восстановления, экран игровых профилей
- [x] Повышенный брокер — **не требуется**: ни одному действию этапа права администратора не нужны. Переключение между
  существующими схемами питания, приоритет `AboveNormal`/`High` своего процесса и `WM_CLOSE` окнам своих неповышенных
  процессов доступны обычному пользователю; `RealTime` запрещён. Обоснование по каждому действию — `docs/ARCHITECTURE.md`, раздел 8.
- [x] **Готово, когда есть тесты на** (проверено 2026-10-19):
  - [x] откат в обратном порядке при сбое Apply — `Apply_failure_rolls_back_applied_actions_in_reverse_order`;
  - [x] восстановление после аварийного завершения (журнал незавершённой сессии) — `Unfinished_session_from_crash_is_restored_at_startup`;
  - [x] конфликт с изменением пользователя — `User_change_after_apply_is_left_alone_and_marked_conflict`;
  - [x] идемпотентность восстановления — `Restore_is_idempotent`.

  Сборка Release с `-warnaserror` — 0 предупреждений; 1025 тестов, все зелёные (вместе с `Category=Host`, которые только
  читают). `06-Verify-Restore.ps1` на пустом журнале — код 0, `session.status = Unknown`. Экспорт с ограниченным токеном
  работает, как на Этапе 1: `isElevated = false`, `monitoring.frame-capture = RequiresAdmin`, ошибок в логе нет.

  По итогам ревью всей ветки исправлено (каждое — тестом, который сначала падал): остановка сессии во время Apply больше
  не запускает оставшиеся действия; подготовленная сессия выполняет профиль в том виде, в каком его подтвердили; второй
  экземпляр Booster не запускается и не восстанавливает чужую активную сессию; запущенная игра с недоступным для чтения
  приоритетом не считается восстановленной, а завершившийся процесс, чей дескриптор кто-то держит, — запущенным;
  «Сохранить» не перезаписывает файл профиля, который при загрузке не принят.

## Этап 5 — Расширенные системные модули

- [x] Реестр (только белый список): только HKCU и только из встроенного каталога, с минимальной сборкой Windows и
  правилом-доказательством (Game Mode, GPU-предпочтение игры на гибридной системе, оптимизация оконных игр); `ask-first`,
  сессия журнала `Maintenance`, возврат кнопкой. Ключи GameDVR в список не входят — только рекомендация
- [x] Память и файл подкачки: выделенная память и предел, пик, кэш, пулы ядра, процессы с наибольшей частной памятью;
  подкачка — только рекомендации L3 с ручными шагами. Двухканальный режим — по-прежнему `Unknown`
- [x] Службы: инвентаризация и классификация (`Protected`, `AntiCheat`, `Microsoft`, `ThirdParty`, `Unknown`); Booster
  службы не останавливает и не отключает, для сторонних с автозапуском — рекомендация L3
- [x] Автозагрузка и оверлеи: `Run`/`RunOnce` HKCU и HKLM, папки автозагрузки, `StartupApproved`; отключение элемента
  HKCU через `StartupApproved` (`ask-first`, сессия `Maintenance`), элементы HKLM — с правами администратора; оверлеи — по
  каталогу, Game Bar — чтение и ссылка на «Параметры»
- [x] Сеть: адаптеры в снимке; ICMP-тест к шлюзу и `network.host` только по кнопке, неответивший узел — `Unknown`
- [x] Накопители: том файла подкачки и место на нём, живая активность ввода-вывода, пока экран «Система» открыт; кэш
  шейдеров не трогается
- [x] DPC/WPR: счётчики PDH `% DPC Time` и `% Interrupt Time` без прав администратора — живые значения и сигнал
  `DriverLatency` в серии бенчмарка; трасса WPR — только по кнопке, `wpr.exe` из System32 через UAC с фиксированными
  аргументами, маркер незавершённой записи
- [x] Журнал стабильности: `EventLogReader` по System и Application (Kernel-Power 41, BugCheck, сброс видеодрайвера,
  WHEA, ошибки диска, Ntfs 55, сбои и зависания приложений), сбои игр из профилей — отдельно
- [x] A/B-тест HAGS: Booster HAGS не переключает; базовая серия → пользователь переключает и перезагружает → серия-кандидат
  → вердикт `BenchmarkComparer` и ручная рекомендация. Переключение засчитывается по времени загрузки и времени записи ключа
- [x] Для всех модулей: тесты, ограничения, подтверждение опасных изменений — каждое изменение `ask-first` и обратимо через
  журнал, остальное — L0 и рекомендации L3; ограничения — `docs/ARCHITECTURE.md`, раздел 11; отчёт — схема 4

  Сборка Release с `-warnaserror` — 0 предупреждений; 1960 тестов, все зелёные (вместе с `Category=Host`). По итогам
  ревью всей ветки исправлено (каждое — тестом, который сначала падал): очистка журнала не удаляет сессию с неудавшимся
  возвратом; советы о трассе WPR называют панель и кнопку так, как на экране; A/B-тест HAGS не засчитывает переключение,
  сделанное после перезагрузки, которую Booster не видел (ключ записан после загрузки — нужна ещё одна перезагрузка).

## Этап 6 — Сеть в игре

Базовый пинг (расстояние до сервера и маршрут провайдера) программа на ПК не уменьшает. Booster показывает, где теряются
миллисекунды, помогает убрать скачки от Wi-Fi и фоновых загрузок и доказывает эффект замером до и после. Устройство —
`docs/ARCHITECTURE.md`, раздел 12.

### 6.1 — Диагностика (только L0 и советы L3)

- [x] Адрес сервера игры: по трафику процессов игры (ETW, с правами администратора), без прав — по таблице TCP с
  предупреждением; кандидаты можно взять кнопкой; ручной ввод — только публичный IP
- [x] Где задержка: шлюз, первый узел провайдера и сервер пингуются одновременно; разбивка «дома», «линия», «маршрут»;
  неответившая цель — `Unknown`
- [x] Трассировка до сервера: узел, на котором пинг вырос и остался высоким до конца маршрута; молчащий сервер — пинг
  последнего ответившего узла
- [x] Скачки: число, период и место — домашняя сеть или дальше шлюза
- [x] Wi-Fi: сигнал, диапазон по номеру канала, скорость соединения, фоновый поиск и режим стриминга — только чтение;
  вызовы, закрытые согласием на местоположение, не делаются
- [x] VPN и туннели: по типу адаптера и словам из каталога; совет выключить на время игры
- [x] Кто нагружает сеть: процессы и службы с наибольшим трафиком во время замера, категории из каталога; без прав
  администратора — `RequiresAdmin`
- [x] Пинг под нагрузкой (bufferbloat): только по кнопке, загрузку запускает пользователь; оценка по росту медианы
- [x] Сравнение до и после: группы по серверу, пометке и действиям Booster; вердикт с оговоркой, разные условия —
  `ConditionsDiffer`
- [x] Советы L3: кабель, 5 ГГц, SQM, VPN, ближний сервер, провайдер или ретранслятор на пробном периоде, Оптимизация
  доставки и Windows Update со ссылками на «Параметры»
- [x] Экран «Сеть в игре», переход с экрана «Система», раздел `gameNetwork` в отчёте JSON и HTML (схема 5), строки в
  `.resx`

  Сборка Release с `-warnaserror` — 0 предупреждений; 2398 тестов, все зелёные (вместе с `Category=Host`).
