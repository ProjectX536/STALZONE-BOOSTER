# STALZONE BOOSTER

Booster — приложение для Windows 10/11 x64, которое честно разбирается, что мешает играм, и меняет только то, что можно безопасно вернуть.

- **Диагностика** оборудования, драйверов и системы: видеокарта и датчики, память и файл подкачки, накопители, службы, автозагрузка и оверлеи, сеть, журнал стабильности, задержки драйверов (DPC).
- **Игровой профиль на время игры** с гарантированным откатом: временная схема питания, приоритет игры, закрытие выбранных вами фоновых программ. После игры и после сбоя всё возвращается.
- **Измерение FPS** через PresentMon: средний FPS, 1% low, frametime P50/P95/P99, рывки. Серии из нескольких прогонов, сравнение «до/после» с оговорками, A/B-тест HAGS.
- **Отчёт** в HTML и JSON.

Booster не обещает фиксированного прироста FPS. Если система работает штатно, он ничего не меняет. Всё, что нельзя узнать надёжно, показывается как «неизвестно», а не придумывается.

## Скачать и запустить

1. Скачайте `Booster.exe` со страницы [Releases](../../releases). Это один файл со встроенной средой .NET, устанавливать ничего не нужно.
2. Запустите. Файл не подписан, поэтому Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».
3. Для измерения FPS нужен PresentMon. Скачайте из того же релиза `Install-PresentMon.ps1` и выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install-PresentMon.ps1
   ```

   Скрипт скачивает PresentMon с официального релиза на GitHub, проверяет SHA256 и кладёт его в `%LOCALAPPDATA%\Booster\tools\PresentMon`. Можно и указать путь к уже скачанному PresentMon в разделе «Настройки».

Экспорт отчёта без окна: `Booster.exe --export <папка>`.

Данные Booster (журнал изменений, настройки, серии FPS, отчёты, логи) хранятся в `%LOCALAPPDATA%\Booster`.

## Права администратора

При запуске Booster запрашивает права администратора (UAC), если они есть у учётной записи. Отказ в запросе отменяет запуск. Под обычной учётной записью Booster запускается без запроса и работает с её правами. `Booster.exe --export` под администратором тоже спрашивает UAC.

Без прав администратора эти функции недоступны или спрашивают UAC отдельно:

- **Замер кадров PresentMon:** нужен администратор или группа «Пользователи журналов производительности» (Performance Log Users). С правами администратора замер идёт без отдельного запроса. Без них для серии FPS Booster запросит подтверждение UAC. Во время игры запрос UAC не показывается: если прав нет, замер не начнётся, и Booster об этом скажет.
- **Трасса WPR** (задержки драйверов): запускается только по кнопке; без прав администратора — через UAC.
- **Элементы автозагрузки для всех пользователей (HKLM):** Booster отключает их только с правами администратора и после подтверждения; вернуть такое изменение тоже можно только с ними.
- **Службы:** Booster их не меняет, только советует.

Ссылки на сайты и страницы «Параметров» Booster с правами администратора передаёт Проводнику: браузер открывается без них.

## Что Booster меняет и как

Каждое изменение записывается в журнал: что, когда, старое и новое значение. Если пользователь сам изменил значение после Booster, восстановление его не трогает.

| Изменение | Когда | Режим |
|---|---|---|
| Временная схема питания | на время игры | спрашивает каждый раз |
| Приоритет процесса игры | на время игры | выключено, включаете сами |
| Закрытие выбранных фоновых программ | перед игрой | спрашивает каждый раз |
| Игровой режим, GPU для игры на ноутбуке с двумя видеокартами, оптимизация оконных игр (только HKCU, из белого списка) | постоянно, кнопка «Вернуть» | спрашивает каждый раз |
| Отключение элемента автозагрузки (для всех пользователей — только с правами администратора; защиту и античит — никогда) | постоянно, кнопка «Вернуть» | спрашивает каждый раз |

## Что Booster не делает никогда

«Очистка RAM», отключение файла подкачки, массовое отключение служб, отключение Defender, реестровые твики из FPS-скриптов, разгон, вольтаж, вентиляторы, XMP, прошивка BIOS, удаление кэша шейдеров, инъекции и чтение памяти игры. Полный список и модель безопасности — [`docs/PRINCIPLES.md`](docs/PRINCIPLES.md).

## Сборка из исходников

Нужен .NET SDK 10.0.402 или новее (`global.json`).

```powershell
dotnet build Booster.sln -c Release
dotnet test --solution Booster.sln -c Release
dotnet publish src/Booster.App/Booster.App.csproj -c Release -r win-x64 -o artifacts/publish
```

Последняя команда собирает тот же один exe, что в релизе. Тесты с `Category=Host` читают настоящую систему и ничего в ней не меняют.

Документация: [`docs/PRINCIPLES.md`](docs/PRINCIPLES.md) — принципы и запреты, [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — архитектура, [`docs/ROADMAP.md`](docs/ROADMAP.md) — этапы.
